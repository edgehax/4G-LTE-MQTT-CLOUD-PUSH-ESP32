# MQTT CLOUD PUSH to ZOHO IoT Cloud over 4G/LTE Network using ESP32

This sample code covers the functionality of reading a sensor data, connect to Zoho IoT cloud and push data over MQTT.
You will need the following to build this project:
- Edgehax 4G LTE with ESP32 board
- Zoho IoT Cloud Account
- 4G SIM Card (Airtel/JIO/Vodaphone/BSNL) with Data Pack
- DHT11 Temperature and Humidity Sensor
- Jumper Cables for connecting Sensor to the Edgehax board
